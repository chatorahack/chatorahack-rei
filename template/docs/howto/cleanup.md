# 自分が始めたものを片付ける

- **誰が実行するか**：AI。自分が起動したもの・作ったものを、区切りごとに片付ける
- **何のためか**：止め忘れた処理や一時ファイルは、エラーを出さずに残り、PC を重くし、ディスクを埋める。気付きにくい
- 決まりは `policy.md` の 2.「始末を付ける」。ここはその手順

## いつ片付けるか

区切りごと：頼まれたことが終わったとき、人の返事を待つとき、引き継ぐとき。長い作業では途中でも。

## 何を片付けるか

| 起動・作成したもの | 片付け方 | 確かめ方 |
|---|---|---|
| ブラウザ（画面あり・画面なし） | 閉じる。終わらなければ、自分が起動したものだけ止める | 同じ名前の処理の数を、起動前と比べる |
| ローカルのサーバ・バックグラウンドのコマンド | 止める。子プロセスが残ることがあるので、止めた後に数える | 待ち受けのポート・処理の数 |
| スクリプトの処理（Python など） | 終わるのを待つか、止める | 処理の数、メモリ |
| 開いたアプリ | 閉じる（人が開いたものは閉じない） | — |
| 一時ファイル・試しに作った書類 | 一時フォルダに置き、要らなくなったら消す | フォルダが空か |

**片付けないもの**：成果物、人が起動・作成したもの、判断待ちのもの（テストのデータなど）。迷ったら消さずに人に聞く。

## ブラウザを使うとき

道具は問わない（自動操作の道具でも、ブラウザを直接起動してもよい）。どちらでも：

- 使い捨ての設定で起動する。このオプションを持つブラウザでは `--user-data-dir` に一時フォルダを渡す。普段の設定（ログイン・履歴・拡張）を使わず、普段のブラウザと処理が混ざらない。終わったら、その設定のフォルダも消す
- 画面なしで撮る・開くときは、終わらない場合に備えて時間の上限を付ける。URL に `&` などが入るときは引用符で囲む（シェルが別の意味に読み、ブラウザが終わらないことがある）

## 重い処理を動かすとき

- 動いている間、メモリと CPU のようすを見る。増え続けるなら止めて人に知らせる
- 終わったら、メモリが空いたことを確かめる
- 大きなファイルを書き出す処理は、書き出し先の空きを先に見る

## 書き方の目安

失敗しても片付くように書く。言語の定番の仕組みを使う：

- `try` / `finally`（例外が出ても片付けが走る）
- Python の `with`（ファイル・一時フォルダ `tempfile.TemporaryDirectory`・自動で操作するブラウザ）
- `subprocess.run(..., timeout=...)` など、時間の上限

## 報告に添える

「片付けたもの：〜。残したもの：〜（理由）」を1行。残したものが無ければ「残したもの：なし」。
