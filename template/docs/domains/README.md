# 分野の地図（domains）

分野ごとに「その分野に既にあるもの」を並べた地図。1分野1ファイル（例：`cooking.md`＝料理）。
初めての相談では、まずここを引く。無い分野・足りない種類だけ Web で調べる（`docs/unknown.md` 4.）。

- `docs/glossary.md`（辞書）＝考え方（YAGNI 等）。この地図＝その分野に何があるか。混ぜない
- **地図と案内を分ける**：地図には残すと決めたものを並べるだけ。今回の目的にどれが関係するかは、その都度 AI が選んで見せる。地図に載っている＝おすすめ、ではない。ただし**足した人＝人間のものは黙って外さない**。今回の目的に関係するものは答えの「既存のもの」の一覧に入れ、関係が薄いものは1行の要約で触れる（例：「地図に人間が足したもの：3件〔サイトA ほか〕。見たいと言えば並べます」）。人間が自分で足したものが黙って消えると、足した意味が伝わらない。全部を毎回並べると、地図が育ったとき案内が埋まる
- 書き方は Awesome リストの決まりに沿う：集めるのではなく選ぶ、なぜ載せるかを一言書く、範囲は1分野に絞る

## 足し方（人間が決める）

0. 見せる既存のものの一覧には番号を振る（「2. 選んで残す」で番号で指せるように）
1. AI は既存のものを見せた後に、1回だけ、選べる形で聞く。判断待ちの問いがほかにある答えでは後回しにする（1つの答えで返す問いは最大2つ。`docs/unknown.md` 5.）。地図が何に使えるか（次のセッション・ほかの人との共有）を一言添える。例：

   > 今回見せたものを、この分野の地図（`docs/domains/〈分野〉.md`）に残しますか？ 地図は、次に相談するときや、ほかの人と共有するときに使えます。
   > 1. 全部残す　2. 選んで残す（番号か名前で。ほかに知っているものも足せます）　3. 今回は残さない　4. この分野では今後聞かない

   - 4. を選ばれたら、地図のファイルの頭に「聞き方：聞かない（YYYY-MM-DD、人間が選んだ）」と書き、以後その分野では聞かない。人間が「残して」と言ったときは、聞き方にかかわらず足す
   - 答えが無いまま次の話に進んだら、残さない（3. と同じ）。もう一度は聞かない
2. 人間の答えで分ける
   - **残す**：地図に足す（足した人＝人間）
   - **違うので直す**：直して足す、または「異論あり」にする
   - **今回は不要**：地図には足さない。今回の記録（台帳）にだけ書く。「誤り」とは別
3. AI が調べて見つけたものは、人間が「残して」と言ったものだけ足す。黙って増やさない。**書く前に、書く行を見せて確かめる**（「地図に次の2件を書きます：サイトA、サイトB。よければ『はい』」）。「それも残して」のように何を指すか両方に読めるときも、この確かめで分かれる（「全部」と読まれることがある）
3a. 新しい分野のファイルを作るときは、先に下の「索引」に1行足し、その名前で作る（次のセッションが別の名前で作らないように）
4. 人間が「残して」と言っても、正しいと保証されたことにはならない。確認日・出典は別に書く

## 索引（分野 → ファイル）

| 分野 | ファイル | 別の呼び方 |
|---|---|---|
| （まだ無い。最初の分野を作るときに足す。ファイル名は英語の小文字とハイフン。例：料理＝`cooking.md`、家計簿＝`household-budget.md`） | | |

## ファイルの形

```markdown
# 〈分野〉の地図

範囲：〈この地図が扱う範囲を1行〉
聞き方：毎回聞く（「聞かない」を選ばれたら、日付つきで書き換える）

## もの
### 道具・サービス
### 公開・共有の場

## 知識
### 定番の型・手法
### 先行例（作品・事例）
### 入門（本・講座）

## 決まり
### 公式の規定・標準・法令（破ると違反になりうる。使う・公開する前に必ず原文で確かめ直す）
```

各見出しの下に表を置く：

| 名前 | なぜ載せるか | URL | 出典 | 足した人 | 確認日 | 状態 |
|---|---|---|---|---|---|---|

- 出典：公式／記事／人間の話
- 足した人：人間／AI が調べた（人間が残すと言ったもの）
- 確認日：最後に出典と照らした日（YYYY-MM-DD）。古いもの（目安：半年以上）を見せるときは、確認日を添えるか確かめ直す
- 状態：使える／古い／終了／異論あり

## 由来

この節の決まり（聞き方・答え方、もの／知識／決まりの分け方、地図と案内を分けること、確認日と状態）は、調べ直すたびに見せるものが変わるのを防ぐためのもの。
