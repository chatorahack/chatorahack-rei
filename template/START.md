## 外の決まり（始める前に一度見る）

契約・規約・法令など、このプロジェクトの外から作業を縛る決まり。全部に答えなくても始められる。「分からない」は下の「仮置き」へ移す。問いの中身と、守れないときの進め方は`docs/external-rules.md`。

| # | 確かめること | 答え（はい／いいえ／分からない／関係なし） | 何で確かめたか（契約の条・規約のURL・聞いた人・日付） | 守れないとき（`decisions/`の番号）・仮置き |
|---|---|---|---|---|
| 1 | 外の AI に渡してよいか（契約・相手先・組織の決まり・AI の提供元の規約）／学習に使わない設定になっているか／渡す先は提供元だけか／AI に渡す権限・認証情報はどこまでか | | | |
| 2 | 個人情報を扱うか／AI に入れる必要があるか／利用目的・同意の範囲の中か | | | |
| 3 | 使うソフト・サービスの入手元が分かっているか、組織が使うことを認めているか／ライセンスの種類と範囲／素材・既存の作品を入れてよいか／使う部品・データの出どころ／実在の人に似せたもの（顔・声・言っていない発言）を作るか／AI が作ったものを相手に渡す・公開してよいか | | | |
| 4 | 守秘義務の範囲／経緯・成果を公開してよいか | | | |
| 5 | やること自体と、作ったものの使われ方（人や会社を傷つける文、なりすまし、架空の口コミなど）が、法令・利用規約に触れないか | | | |
| 6 | 相手先・公開先が、AI を使うことを禁じていないか、開示を求めていないか | | | |
| 7 | AI の出力を、誰がどう確かめてから外に出すか | | | |
