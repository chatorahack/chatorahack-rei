# 使用例

REI の雛形を使うと、何がどう埋まるかを見るための例です。雛形（`template/`）には入れていません。プロジェクトに写すのは `template/` の中だけです。

| ファイル | 何が分かるか |
|---|---|
| `notice-page-update/conversation.md` | 人が3回話しかけたときの AI の返事。初めての分野（画像の代替テキスト）で、先に分野の地図と簡易診断を見せ、決めるのは人に返す |
| `notice-page-update/project/` | そのやり取りの後に埋まったファイル。台帳の1行（入口・出口）、決定ファイル、引き継ぎ、作業記録、直したページ |
| `hook-examples.md` | 「止めて」、決定ファイルの書き換え、プロジェクトの外への書き込み、コミット前の関門で、何が出るか |

## 見どころ

- `project/ledger/task_log.md`：「入口」に人の最初の言葉がそのまま、「出口」に結果が入る
- `project/decisions/0001-top-image-alt.md`：人が決めたことを、決めた人・選んだ理由・覆す条件と一緒に残す
- `project/handoff.md`：次のセッションが最初に読む「今どこ」「次の一手」「判断待ち」
- `conversation.md` のターン2：見ていないもの（画像そのもの、公開前のチェックの結果）を「未確認」と書いて人に返す

## この例で AI が見落としたこと

架空の題材で動かした記録です。時刻と一部の言葉を見本の形にそろえたほかは、そのまま載せているので、うまくいかなかったところも残っています。

- `task_log.md` の TASK-1 で、「出口」は「解決」に書き換えたのに、「状態」の欄は「保留」のままです。記録は人が確かめる前提です
- ターン2で、作業記録を書くコマンドが1回失敗し、AI が書き直しています
- コミットはしていません。この例は、コマンドを前もって許していない設定で作ったので、AI が `git config` で著者名義を確かめようとしたところで、人の許しを待って止まりました

## どう作ったか

- 版：REI 0.3.0-beta.9 の雛形。Claude Code、モデルは Claude Sonnet
- 手で書かずに、雛形を写したフォルダで Claude Code を実際に動かして作りました。hook の例も、hook を実際に動かして書き出しています
- 雛形が新しい版になると、この例と食い違うことがあります。**雛形と違うときは、雛形が正です。**
