# 0001: トップ画像の代替テキスト

- 日付：2026-11-02
- 決めた人：人間（依頼者）
- 決めたこと：`site/news.html` のトップ画像（`images/top-winter.png`）の alt を「冬のお知らせ 12月1日から受付時間が変わります」にする。画像内の文字をそのまま使う
- 検討した選択肢（既存の解決策を含む）：WCAG 1.1.1 / W3C WAI の判断ツリーにある3種（飾り＝`alt=""`、情報入り＝内容を書く、リンク・ボタン＝行き先を書く）。画像に文字があるため「情報入り」を選んだ
- 選んだ理由：画像内の文字が伝える内容を、見えない人にも同じ内容で伝えるため（人間の判断）
- 覆す条件：画像を差し替えて文字が変わったとき。公開前のチェックの基準が別の書き方を求めたとき
