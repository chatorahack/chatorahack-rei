# 3. 「止めて」で止める

前もって済ませること：[チュートリアルの入口](README.md)の「始める前に」。

**覚えること**：「止めて」と言うと、プロジェクトの中に印のファイル（`.claude/stop-requested`）が置かれ、人がそれを消すまで、AI は道具（ファイルを読む・書く、コマンドを使うなど）を使えなくなります（hook が動いているときです。強制ではありません）。

**打つ言葉**（何か頼んだあとで。たとえば「`handoff.md` を読んで、今の状態を教えてください」と頼み、答えが返ってから）：

```text
止めて
```

**起きること**：

- ［機械］プロジェクトの中に `.claude/stop-requested` という印ができています
- ［AI］AI は何をしていたか（何もしていなければ「何もしていません」）を短く伝えて、次の指示を待ちます
- ［機械］そのあと何か頼むと（たとえば「`handoff.md` をもう一度読んでください」）、AI が道具を使おうとしたところで断られます（`stop-guard`。AI が試さずに「止まっています」と答えることもあります）

Claude Code の Esc キーでも、その場の動きを止められます。Esc は印を置かないので、次に頼めば AI はまた道具を使えます。続けて止めておきたいときは「止めて」を使います。

**再開のしかた**：Claude Code の外（Git Bash など）で、プロジェクトのフォルダに移ってから印を消します。

```sh
cd <試し用のフォルダ>
rm .claude/stop-requested
```

**気をつけること**：拾う言葉は「止めて」「やめて」「ストップ」の3つで、文の途中でも拾います。「その案はやめておきます」「動画を止めてから続きを見る方法を教えて」でも止まります。英語の "stop" では止まりません。意図せず止まったら、上の「再開のしかた」で印を消してください。詳しくは `docs/troubleshooting.md`。
