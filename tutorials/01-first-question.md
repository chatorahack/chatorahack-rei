# 1. 初めての分野の相談

前もって済ませること：[チュートリアルの入口](README.md)の「始める前に」。

**覚えること**：REI は、作り始める前に「既にあるもの」を見せ、決めるのは人に返します。

**打つ言葉**（Claude Code に）：

```text
小さな Web ページを作ってみたいです。初めてなので、何から始めればいいですか？
```

**起きること**：

この回の「起きること」は、どれも［AI］（AI への指示による動き）です。起きないときは、下の「うまくいかないとき」へ。

- ［AI］答えの最初に、その分野の地図（定番の仕組み・既にある道具やサービス・公式の決まり）が出ます
- ［AI］「どれを使うか」は決めずに、選ぶための材料と、最初の一歩が返ってきます
- ［AI］地図に残すかを聞かれることがあります（残す・選んで残す・残さない、などから選べます）。残すと答えると、書く行を先に見せて「この内容で書いてよいですか」と聞かれることがあります

**確かめる場所**：

- ［AI］`ledger/task_log.md` に今の相談が書かれています。新しい行ができて「入口」に今の言葉が入るか、「始めます」のときにできた行（TASK-1 など）がまだ開いていれば、その行に書き足されます。「出口」には結果（「保留：〜」など）が入ります。どこにも無ければ、「台帳に書いてください」と頼んでください
- ［AI］残すと答えたなら `docs/domains/` に分野のファイルができています

**うまくいかないとき**：地図が出ずにいきなり手順が始まったら、「先に、その分野で既にあるものを見せてください」と頼んでください。
